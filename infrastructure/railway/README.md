# Railway and SFTPGo Placeholder

Railway will later host SFTPGo with public TCP proxying for partner-facing SFTP workflows.

No SFTP service is implemented in this foundation milestone.

Future configuration placeholders:

- `SFTP_PUBLIC_HOST`
- `SFTP_PUBLIC_PORT`
- `SFTP_USERNAME`
- `SFTP_SSH_PRIVATE_KEY_PATH`
- `SFTP_SSH_PUBLIC_KEY`
- `APP_ENV`

Private keys and generated credentials must stay in Railway variables or another secure secret store. Do not commit them.
